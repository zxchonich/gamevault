# GameVault

GameVault — веб-застосунок для агрегації персональних ігрових бібліотек: каталог ігор, особиста бібліотека зі статусами проходження, рецензії, друзі, стрічка активності та персональні рекомендації з інтеграцією Steam.

## Технології

- Python 3, Django 6
- MySQL (utf8mb4)
- HTML, CSS, JavaScript (без фреймворків, світла й темна тема)
- Steam OpenID, Steam Web API, Steam Store API, Google OAuth 2.0

## Можливості

**Акаунти**
- реєстрація з підтвердженням email, вхід за логіном або email, відновлення пароля;
- вхід і реєстрація в один клік через Steam або Google, прив'язка кількох способів входу до одного акаунта;
- обмеження спроб входу, вимоги до надійності пароля, вихід з інших сесій після зміни пароля.

**Каталог і бібліотека**
- каталог ігор із пошуком, фільтрами за жанрами та сортуванням;
- сторінка гри: опис, оцінки, хто з друзів грає, схожі ігри;
- особиста бібліотека зі статусами («Планую», «Граю», «Пройдено», «Відкладено», «Закинуто»);
- рецензії та оцінки, середній рейтинг гри;
- заявки на додавання ігор, яких немає в каталозі, з модерацією.

**Соціальне**
- профілі користувачів з приватним режимом (профіль і бібліотека видно лише друзям);
- друзі та заявки в друзі;
- стрічка активності (своя та друзів) і блок «Зараз грають»;
- сповіщення: заявки в друзі, прийнята дружба, рішення щодо заявки на гру.

**Рекомендації**
- бал 0–100 з урахуванням улюблених жанрів (статуси, оцінки, години в Steam), ігор друзів і якості гри;
- пояснення, чому гру рекомендовано, і кнопка «Не цікаво».

**Steam**
- синхронізація бібліотеки: час у грі, нещодавно запущені ігри, статус нових ігор за активністю;
- автоматична синхронізація у фоні (раз на кілька годин) і команда для Планувальника завдань;
- ігри зі Steam-бібліотеки автоматично потрапляють у каталог разом з описом, жанрами й обкладинкою;
- сторінка Steam-бібліотеки з кнопками запуску ігор.

**Адміністрування**
- керування іграми, жанрами й рецензіями, модерація заявок;
- зіставлення ігор каталогу зі Steam, заповнення даних і постерів зі Steam Store.

## Запуск

1. Створити віртуальне середовище та встановити залежності:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Скопіювати `.env.example` у `.env` і заповнити значення:
   - `DJANGO_SECRET_KEY` і параметри MySQL — обов'язково;
   - `STEAM_API_KEY` — для інтеграції зі Steam (https://steamcommunity.com/dev/apikey);
   - `EMAIL_*` — для надсилання листів; якщо `EMAIL_HOST` порожній, листи виводяться в консоль `runserver`;
   - `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` — для входу через Google (без них кнопка не показується).

3. Створити базу даних і завантажити схему:

```bash
mysql -u root -p -e "CREATE DATABASE game_library_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -u root -p game_library_db < database/schema.sql
python manage.py migrate
```

Таблиці застосунку не керуються міграціями Django: `migrate` створює лише службові таблиці
(сесії, адмінка). Зміни схеми зберігаються як SQL-файли в `database/migrations/`, а
`database/schema.sql` містить актуальну повну схему.

4. Запустити сервер:

```bash
python manage.py runserver
```

Щоб призначити користувача адміністратором, встановіть йому `role_id = 2` у таблиці `users`.

## Корисні команди

```bash
python manage.py test library --keepdb      # тести (потрібен запущений MySQL)
python manage.py verify_email <логін>       # вручну підтвердити email користувача
python manage.py sync_steam_all [--all]     # синхронізувати застарілі Steam-бібліотеки
python manage.py fetch_steam_apps           # завантажити дані Steam Store для всіх ігор
python manage.py hash_plain_passwords       # захешувати паролі, що зберігаються відкритим текстом
```

Для щоденної синхронізації Steam можна створити завдання в Планувальнику завдань Windows:
програма `venv\Scripts\python.exe`, аргументи `manage.py sync_steam_all`, робоча папка — корінь репозиторію.

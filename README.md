# GameVault

GameVault — веб-застосунок для агрегації персональних ігрових бібліотек, роботи з каталогом ігор, рецензіями, друзями та рекомендаціями.

## Технології

- Python, Django
- MySQL
- HTML, CSS, JavaScript
- Steam Web API, Steam Store API

## Основні можливості

- реєстрація та авторизація користувачів;
- каталог ігор із фільтрацією та пошуком;
- персональна бібліотека ігор;
- статуси проходження;
- рецензії та оцінки;
- профілі користувачів (з приватним режимом);
- друзі та заявки;
- персональні рекомендації;
- адміністративне керування іграми, жанрами та заявками;
- інтеграція зі Steam:
  - вхід через Steam і синхронізація бібліотеки (час у грі, нещодавно запущені ігри);
  - Steam-бібліотека з запуском ігор і пропозиціями ігор до каталогу;
  - автоматичне додавання ігор каталогу до бібліотек їхніх власників у Steam;
  - заповнення даних і постерів ігор зі Steam Store.

## Запуск

1. Створити віртуальне середовище та встановити залежності:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Створити файл `.env` за зразком `.env.example` і вказати параметри MySQL та `DJANGO_SECRET_KEY`.
   Для інтеграції зі Steam потрібен `STEAM_API_KEY` (https://steamcommunity.com/dev/apikey).

3. Створити базу даних і завантажити схему:

```bash
mysql -u root -p -e "CREATE DATABASE game_library_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -u root -p game_library_db < database/schema.sql
python manage.py migrate
```

Таблиці застосунку не керуються міграціями Django: `migrate` створює лише службові таблиці
(сесії, адмінка). Зміни схеми зберігаються як SQL-файли в `database/migrations/`.

4. Запустити сервер:

```bash
python manage.py runserver
```

Щоб призначити користувача адміністратором, встановіть йому `role_id = 2` у таблиці `users`.

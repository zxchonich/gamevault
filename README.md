# GameVault

GameVault — веб-застосунок для агрегації персональних ігрових бібліотек, роботи з каталогом ігор, рецензіями, друзями та рекомендаціями.

## Технології

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## Основні можливості

- реєстрація та авторизація користувачів;
- каталог ігор із фільтрацією та пошуком;
- персональна бібліотека ігор;
- статуси проходження;
- рецензії та оцінки;
- профілі користувачів;
- друзі та заявки;
- персональні рекомендації;
- адміністративне керування іграми, жанрами та заявками.

## Запуск

1. Створити віртуальне середовище.
2. Встановити залежності:

```bash
pip install -r requirements.txt
```
